1️⃣ Introduction & Architecture Philosophy

Welcome to WeatherGlow 👋, engineered by NEURON TS LABS. WeatherGlow delivers real-time meteorological conditions, air quality index (AQI) metrics, and customizable transparent home screen clock widgets.

The application is built around an on-demand, privacy-first processing architecture. We fundamentally reject background surveillance and location profiling paradigms. Personal identification details are never collected, and weather calculations run without maintaining server-side user tracking ledgers.

2️⃣ Information We Collect & Process

📍 A. Location Data

  • Permissions Requested: Precise Location (ACCESS_FINE_LOCATION) and Coarse Location (ACCESS_COARSE_LOCATION).
  • When It Is Accessed: Exclusively when you tap the "Current GPS" action or enable automatic local area detection during onboarding or settings configuration.
  • Operational Purpose: Coordinates (latitude and longitude) are resolved via Android Geocoder into recognizable area names (e.g., locality, district, city) to fetch accurate real-time forecasts, hourly/5-day trends, UV levels, and sunrise/sunset times.
  • Storage & Retention: Coordinates are processed ephemerally in volatile memory (RAM) and stored only within your device's local database (weather-glow.db). Movement history trails are never recorded or uploaded to remote servers.

⚙️ B. User Preferences & Local Offline Caches

  • Stored Datasets: Saved cities, default location targets, temperature units (°C / °F), wind speed and barometric pressure units, UI themes (Light, Dark, AMOLED Glass), and recent forecast response bodies.
  • Storage Architecture: Stored locally using Android DataStore Preferences and an encrypted local Room SQLite Database. This data stays on your physical device.

📱 C. Technical Identifiers & Diagnostics

  • Parameters Handled: Device hardware model, operating system version, display resolution, system language, IP address, and Google Advertising ID (GAID).
  • Operational Scope: Enables correct widget scaling, maintains network handshakes with weather API endpoints, monitors application stability, and serves non-intrusive banner advertising.

4️⃣ Android System Permissions Transparency

WeatherGlow declares and uses only the minimum permissions necessary to deliver forecasts and support desktop widgets:

Permission Category Operational Scope Mandatory?
ACCESS_FINE_LOCATION 🛰️ Location Resolves high-accuracy GPS coordinates when tapping "Current GPS" for local weather. Optional
ACCESS_COARSE_LOCATION 📡 Location Determines approximate location via cellular/Wi-Fi networks for regional forecasts. Optional
INTERNET 🌐 Network Retrieves live weather data from OpenWeather and loads banner ad placements. Yes
ACCESS_NETWORK_STATE 📶 Network Verifies active internet connectivity prior to firing forecast update requests. Yes
RECEIVE_BOOT_COMPLETED 🔄 System Restores and updates home screen clock and weather widgets following device reboots. Optional

🛑 Background Location Policy:

  • WeatherGlow does not request or declare ACCESS_BACKGROUND_LOCATION.
  • Location coordinates are resolved exclusively while the application is active in the foreground or during explicit user-triggered widget updates.

5️⃣ Third-Party Services & SDK Integrations

WeatherGlow connects with trusted third-party providers to deliver global meteorological data and maintain free software distribution:

⛅ A. OpenWeather API (Weather Service Provider)

  • Role: Weather vendor providing live temperatures, atmospheric pressure, AQI metrics, and 5-day forecasts.
  • Data Shared: Ephemeral latitude/longitude coordinates and city search strings.
  • Privacy Details: Handled under the OpenWeather Privacy Policy.

📍 B. Google Play Services (Fused Location Provider)

  • Role: Battery-efficient location detection and native Android reverse geocoding routines.
  • Data Handled: GPS signals, Wi-Fi networks, and device location states.
  • Privacy Details: Handled under the Google Privacy Policy.

📢 C. Google Mobile Ads (AdMob)

  • Role: Delivers contextual and personalized banner advertisements.
  • Data Collected: Advertising IDs (GAID), device specifications, coarse IP location, and interaction logs.
  • Privacy & Opt-Out: Manage ad targeting via Google Ads Settings or review the AdMob Privacy Policy.

6️⃣ Local Storage & Security Architecture

  • 🗄️ Local Sandboxing: Saved cities, default locations, and cached weather records reside strictly in the app-private SQLite database (weather-glow.db), shielded from other installed apps.
  • 🔐 Encrypted Network Calls: All external API requests and ad calls use encrypted HTTPS/TLS transport encryption.
  • 🛡️ Zero Remote Tracking Infrastructure: NEURON TS LABS does not operate remote servers to aggregate user locations, movement logs, or behavioral profiles.
  • 💾 Data Retention: On-device records remain stored until you remove cities in-app, clear application storage, or uninstall the software.

7️⃣ User Rights & Data Control Options

You have full authority over your data within WeatherGlow:

  • 📍 Revoke Location Access: Disable location permissions anytime via Android Settings > Apps > WeatherGlow > Permissions. You can still manually search and save any city worldwide.
  • 🗑️ Manage Saved Locations: Delete individual cities or clear your entire saved locations list in the Locations tab.
  • 🧹 Flush Local App Data: Clear all cached weather responses and settings via Android Settings > Apps > WeatherGlow > Storage > Clear Data.
  • 🆔 Reset Ad Identifiers: Reset or delete your Google Advertising ID via Android Settings > Google > Ads.
  • ❌ Complete Package Erasure: Uninstalling WeatherGlow immediately removes all local databases, DataStore preferences, and widget cache files from your device.

8️⃣ Children’s Privacy & Regulatory Governance

WeatherGlow is a general utility and is not directed at children under the age of 13 (or 16 in specific regional jurisdictions). The application does not knowingly harvest personal information from children.

🌐 Regional Compliance Alignments:

  • 🇪🇺 GDPR (European Economic Area): Processing relies on legitimate interests (delivering localized forecasts). Ad consent adheres to Google's EU User Consent Policy.
  • 🇺🇸 CCPA / CPRA (California): We do not sell or share personal consumer information for cross-context behavioral advertising.
  • 🇮🇳 Digital Personal Data Protection Act (India): Processing strictly complies with digital purpose-limitation guidelines.
