Privacy Policy for VX Player

Package Name: com.neurontslabs.vxplayer • Effective Date: 5 August 2026

1. Introduction

This Privacy Policy explains how VX Player (“the App”, “we”, “us”, or “our”), developed by NEURON TS LABS, handles information when you use the App on Android devices.

VX Player is designed as an offline-first, local media player. Its core purpose is to play video and audio files that already exist on your device, and optionally to protect selected files in a Private Vault on that same device.

Core Privacy Directives:

  • The App does not declare or use the Android INTERNET permission.
  • The App does not stream media from the internet as part of its core product design.
  • The App does not operate user accounts, cloud libraries, or remote sign-in.
  • Media files, playback history, settings, vault contents, and vault security credentials are stored on your device only.
  • We do not sell personal data or utilize advertising/analytics SDKs in the core App shipped for Google Play.

3. Scope & Privacy Principles

This policy covers the VX Player application, library indexing, local playback features, Private Vault, biometric gates, and local cache layers. We adhere strictly to 6 key principles:

  • Local by default: Core features run completely offline without network triggers.
  • Minimal data boundary: We process only the minimum metadata necessary to render local media and persist playback options.
  • No cloud media backend: Your media files are never hosted or streamed from external server hardware.
  • User sovereign control: Reset vault PINs, wipe playback history, or flush caches directly from the UI.
  • Zero advertising ID harvesting: No tracking vectors or advertising profiles are compiled.
  • Private Vault security: Isolated sandbox structures protect sensitive media locally from casual device inspection.

4. Information Processed On-Device

Because VX Player operates entirely offline, all processing takes place locally inside your Android device runtime:

A. Local Media Library Metadata

When media permissions are granted, the app indexes local paths, display names, folder structures, duration, file sizes, container metadata, MediaStore IDs, and locally generated thumbnail previews into a local Room Database. This database is never transmitted off-device.

B. Playback State & Incognito Mode

Unless Incognito playback is enabled, last-watched positions, playback speeds, preferred audio tracks, and subtitle style choices are written locally to maintain session state. When Incognito mode is active, the app blocks history and resume logging entirely.

C. Private Vault Architecture & Biometrics

Items moved into the Private Vault are copied into app-private storage guarded by anti-indexing markers (.nomedia). Security credentials (like your Vault PIN) are stored strictly as salted, local cryptographic hashes. Biometric unlock routines delegate matching directly to the Android OS secure hardware (BiometricPrompt)—VX Player never reads or stores raw biometric templates.

D. Caches and Performance Diagnostics

Temporary thumbnails (Coil disk cache) and seek-bar scrub frames are kept in disposable local cache layers with size-capping safeguards. Diagnostics shown in the About & Diagnostics view remain strictly on-screen for support troubleshooting and are never broadcast externally.

5. Android System Permissions

VX Player requests permissions solely to interface with local files and hardware decoding pipelines:

Manifest Permission Operational Scope Network Access
READ_MEDIA_VIDEO / READ_EXTERNAL_STORAGE Discovers and indexes local device video files for playback and thumbnail generation. No
READ_MEDIA_AUDIO Reads local audio files and external audio tracks for multi-track synchronization. No
FOREGROUND_SERVICE_MEDIA_PLAYBACK Sustains background audio and media session notifications while the app is minimized. No
USE_BIOMETRIC Interfaces with native OS biometric prompts to unlock the Private Vault. No

Explicitly Banned Permissions: VX Player intentionally omits INTERNET, ACCESS_FINE_LOCATION, READ_CONTACTS, READ_SMS, and CAMERA.

6. Data Retention & Erasure Controls

Since all application variables reside locally, uninstalling VX Player immediately wipes all app-private storage, including local database indexes, preference settings, and vaulted private media copies. Original unvaulted media files located in shared public directories remain under your control in system storage.

You can clear history, flush thumbnail caches, or reset vault indexes at any point by navigating to Settings → Clear Storage / Data inside Android system settings or utilizing in-app maintenance tools.
